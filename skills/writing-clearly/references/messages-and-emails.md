# Messages and emails

## Make a message sendable

The instruction, verbatim:

> Rewrite the selected text into a sendable message. Preserve the author's intent, factual claims,
> language, register, and level of directness. Make it clear, human, and ready to send.
>
> Remove filler, repetition, false starts, and unnecessary hedging.
>
> Keep names, dates, numbers, technical terms, URLs, and quoted text intact.
>
> Do not add new claims, promises, explanations, apologies, enthusiasm, or marketing language.
>
> Do not make the message more formal or casual than the input requires.
>
> Add only the minimal connective wording needed to make the message readable.
>
> If the selected text is already a good message, return it with only small corrections.
>
> Return ONLY the message. No preamble, no commentary, no headings.

In practice:

| Dimension | Preference |
| --- | --- |
| Tone | Natural, human, direct |
| Formality | Match the original context |
| Length | Concise, without losing meaning |
| Voice | The user's own; it should sound like they wrote it, only clearer |
| Accuracy | No invented information or commitments |
| Editing | The minimum needed |
| Politeness | No unnecessary apologies or pleasantries |
| Enthusiasm | No artificial positivity or marketing tone |
| Output | Only the finished message |
| Next step | An explicit request or next action when the message needs one |

## Distill

A separate operation: compress a text by about 40–60% while keeping everything the reader acts
on. The result is a compact summary of the essential information, not necessarily a message you
could send.

## Emails to a group

- Before writing to a group, read earlier emails the user sent to that same group and match their
  tone, greeting, structure, font, sender address and sign-off.
- Hand over a draft; the user edits and sends it.
